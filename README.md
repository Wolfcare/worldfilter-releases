# World Filter releases

Downloads for **World Filter**, a dual multimode filter sound-design strip (AU + VST3) by Obscura Lux.

Go to **[Releases](../../releases/latest)** and download `WorldFilter-<version>-macOS.dmg`
(macOS 12 or later, Apple Silicon and Intel). World Filter needs a license file to process audio.

World Filter checks this page for new versions and can install them by itself (Options ▸ Updates).
Each release includes `worldfilter-update.json`, which lists the update package with its size and
SHA-256 hash, and `worldfilter-update.json.sig`, an RSA signature of that file. World Filter installs an
update only if the signature, the hash and the Apple Developer ID code signature all check out.
